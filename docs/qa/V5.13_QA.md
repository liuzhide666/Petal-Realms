## Limits and deployment

Native iOS Safari and hardware frame-time measurements are not certified. Reduced motion covers new effects; legacy particles/portals are a separate review. The current rock lookup is a fixed 3x3 cell query and needs a radius-aware completeness audit before unusually large new bodies are introduced. Monster pair enumeration remains O(n²).

This candidate requires successful GitHub CI and a Cloudflare preview before production promotion. Deployment identifiers are reported separately after promotion. Account schema, canonical production database binding, recovery semantics and save conflict handling are unchanged. Production contains no destructive migration in this release.
