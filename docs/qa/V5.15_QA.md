## Corrections and regression boundaries

The old offline browser harness matched a single hardcoded asset query version and therefore failed to inline updated files. It now accepts the versioned rules/art script tags while still loading exact checkout bytes. The real HTTP asset suite verifies runtime loading independently. A craft test must choose its material through the UI before checking the selected-material distribution; opening the craft menu intentionally clears that selection.

Attack coefficients are shared with previews, but the rays are conditional visual estimates. Obstacles, future frost expiry, rage changes and re-aiming during windup can change realized trajectories. The charge capsule is a conservative visual body envelope. Single-hit damage is conditioned on one independent eligible melee hit and is not a DPS prediction. Native Safari hardware and cross-platform deterministic replay are not verified. No authoritative multiplayer/economy claim is made.
