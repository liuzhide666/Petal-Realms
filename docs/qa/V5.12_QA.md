# V5.12.1 · 操作审查与图鉴收集追踪

本轮审查：2026-10-19（北京时间）；V5.12 基础实现：2026-10-18。此文件记录实现与本地证据；生产版本仍须按实际部署 SHA 核对。

## 本批实现

- 固定动态视口、禁止页面回弹，表单输入最小 16px；游戏按钮、画布不选字／不弹出文本菜单，凭证输入框仍可复制。
- 手机竖屏 9–10 槽双行、矮横屏两行并采用纵向动作区；分开背包与触控区，技能托盘可收起，取消手势和后台切换释放按键／触摸。
- 桌面鼠标跟随或纯键盘移动，WASD／方向键优先；键位依据物理 code。鼠标点击 HUD 后焦点回画布，键盘 Tab 导航仍保留原生按钮激活。
- 收集目标、已拥有统计（含两套装备）、产出地图路线、目标达成提示和持久化；旧存档没有 goal 字段仍可读取，服务端验证可选目标。
- 已发现生物的图鉴可选目标品质并追踪其掉落；守卫栖息地包含其独立生成规则。收集目标的类型与数值品质先过滤，再进入存档。
- 系统取消触控拖拽只清理拖影，正常松手才可换装。
- 中立漫游生物受到伤害后反击 8 秒，未继续受击则恢复退避／漫游。
- 精简登录、帮助、背包、合成、图鉴和设置文案；旧账号迁移与碰撞轮廓折叠，当前原生账号不显示旧位置房间入口。

## Florr 参考边界

查阅 https://florr.io/ 官方页面。官方公开介绍强调战斗和收集稀有花瓣；浏览器可见官方登录／游客入口及花瓣视觉。详细游戏内规则未成功进入验收，不将社区 Wiki 作为官方数值来源。本批据此加强“选目标 → 找产出区域 → 战斗／合成 → 更新构筑”的循环；路线追踪和反击参数属于本游戏设计，不声称逐条复刻官方机制。
