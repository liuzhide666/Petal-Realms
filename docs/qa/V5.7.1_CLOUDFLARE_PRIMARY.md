# Petal Realms V5.7.1 — Cloudflare-first release acceptance

Date: 2026-10-17. Target primary origin: https://petal-realms.pages.dev .

## Changes
1. Cloudflare Pages is now the canonical link and public game host, including HTML canonical/OpenGraph.
2. Email confirmation and password recovery target the **canonical Cloudflare Pages origin** on all non-legacy hosts, including preview builds; only the exact legacy Netlify HTTPS origin retains its old callback.
3. Legacy Netlify login shows a non-destructive migration advisory instead of forcibly redirecting. It warns that browser localStorage does not migrate between domains.
4. Live/offline **device network status** is visible in the login panel, not misleadingly presented as successful Supabase sync.
5. Automatic login failure is passed through the existing localized Supabase error mapping.
6. Cloudflare Pages static headers include content type, referrer, frame, privacy permissions, and no-cache HTML delivery.
7. Supabase database, RLS, payload format, account credentials and server-side secrets are unchanged.

## Automated and platform gates
- `node tests/cloudflare_pages.cjs` tests seven strict host cases, canonical metadata, signup/recovery callback, migration banner, offline display and cache/security headers.
- Existing GitHub Actions: JS syntax, cloud save mock, error mapping, talent/shrine, tactical AI, Realtime protocol.
- Deploy only after green PR CI and successful `main` Actions. Confirm Cloudflare Pages latest production deployment SHA exactly equals merge SHA. No "deployed" claim from preview alone.

## Not yet live accepted
- Supabase Auth URL Configuration must include `https://petal-realms.pages.dev/**`; its Site URL can be changed to the primary origin once dependent clients are checked. This connector cannot read/modify the Auth URL Configuration.
- No real email delivery, password-reset mail, native Safari/HarmonyOS or two-account cross-device save verification is asserted.
- Existing local-only characters on the Netlify origin do not automatically appear on Cloudflare; save migration must be evaluated before decommissioning the legacy site.
