## 已实现

- 损坏本机存档停止静默重建；上一份有效副本恢复；没有副本时，在本机密码验证后提供文件恢复入口；保留一份损坏记录。

- 保存失败时导出当前内存进度；手动保存不再错误显示成功。Cloudflare 角色导出也复用该入口。
- 左侧分类材料、右侧配方与按钮；单合、最多五次批量合、选中材料组全合。保留保护锁、装备隔离、最高品质和满仓边界。
- 全合不连续升级产物，不消耗其他组；单次短汇总动画与真实回执。写入失败撤销库存变更；跳过、关闭、减少动画不能重复结算。
- 更新相应 CI、概率详情展开交互、受控动画时钟及版本规范，数值系数保持不变。

## 状态与限制

代码、规则和本地验证完成；候选 PR 及其当前 CI 结果以 GitHub 直接状态为准。本轮没有合并 main、没有生产部署、没有迁移生产数据。新代码的线上状态尚未验收。

浏览器模拟触控与屏幕尺寸不等于 iPhone Safari、Android 真机和低性能设备实测；真实跨设备登录、断网重连、云端写入后的刷新恢复仍需针对预发布环境验收。本轮没有修改合成概率、增加保底或调整战斗经济，不将已有非单调品质进阶解释为重新平衡完成。
