## Operational boundaries

Email delivery, production SMTP, signup confirmation, RLS negative tests with real users, and cross-device recovery have **not** passed live acceptance. Existing local player accounts are not migrated automatically. Supabase email Site URL / redirect whitelist must include the production origin. The production site is: https://stellular-khapse-5c19f8.netlify.app .

The remember-me feature stores a Supabase refresh token (not a password) in browser localStorage, so users on shared devices should disable it and log out. This is a client-side SPA; same-origin script security remains material. Do not place any private server key in the HTML.
