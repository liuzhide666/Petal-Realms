# V5.9.2 · 精准旋转碰撞与可视反馈

日期：2026-10-18。正式发布目标：https://petal-realms.pages.dev

## 问题

V5.9 的怪物朝向已有方向性椭圆，但接触算法把“椭圆中心到轮廓的径向距离”当作两个几何体沿法线的支持距离。两者在斜向角度并不相同，造成花瓣擦边命中、玩家受伤或怪物之间的分离边界有可见差异。

## 已修正

1. `mobCircleOverlap` 使用坐标反旋转＋单调拉格朗日乘子二分，求**椭圆与圆形最近点**，并提供包围圆快速排除及内部快速返回。在固定每帧逻辑中，18 次二分仅发生于靠近边界的检测。
2. `mobSupportRadius` 改为椭圆的法线投影支持函数，供怪物与怪物的分离保守判断使用。
3. 玩家与怪物的身体碰撞调用相同的椭圆－圆形最近点函数，避免和花瓣命中使用不一致的近似。
4. 常规怪物、软体怪、泡泡以及机械单位的主体形状更贴近其真实碰撞轮廓；朝向渲染不再使用与物理朝向不一致的摆动角。
5. 在原有「显示碰撞轮廓」开关中可同时查看花瓣的实际接触圆，方便测试与平衡。
6. 保留 V5.9.1 单次/批量合成概率、原有等级/掉落、每 60Hz 最多十击、装备、账号、存档与 Supabase 表结构。

## 自动检查

- 新增 `tests/v592_collision_precision.cjs`：基于 2048 点椭圆边界的确定性数值对照，覆盖方向旋转、细长/宽扁敌人、斜向支持函数、精确花瓣接触与玩家接触。
- 旧有 `tests/v59_gameplay_auth.cjs`、`tests/v591_batch_craft.cjs`、云存档、邮件注册和战斗回归必须继续通过。
- GitHub Actions PR 门禁通过后才能合并；Cloudflare Pages Production 必须与 GitHub 最新提交完全一致。

## 边界和未验收

- 怪物外部装饰（长足、翅膀、尖刺）不是全部可伤害碰撞区域；保留主体碰撞设计，避免因装饰造成“空气墙”。
- 椭圆－椭圆推挤使用沿中心法线的保守支持函数，不是任意旋转椭圆完整连续碰撞算法。玩家／花瓣和怪物接触使用精确椭圆－圆形算法。
- 没有修改 Supabase Authentication 的 Confirm Email、SMTP 配置或真实玩家存档；注册验证邮件是否能够送达仍需手动验收。
- 实机 Safari／鸿蒙触屏长时间性能和实时多人服务器战斗未验收。
