# V5.9 QA · petals, directional creature hitboxes, inventory and verified-email auth

Date: 2026-10-17. Canonical host: https://petal-realms.pages.dev .

## Implemented
- Petal world rendering 80% of original dimensions and shared hit radius defined by `petalContactRadius` for creature and obstacle collisions. Existing 60Hz fixed-step, break/reload, durability ratio, 10-strike cap and per-petal stats preserved.
- Creature sprite facing interpolates toward movement/charge direction. Directional elliptical support radii depend on archetype (ant/termite/mantis, beetle, flying insects, spiders, robots, blooms). Body, mob separation and petal strike interaction use these rotated silhouettes; nearby rock relaxation uses conservative circumscribed radius. Debug visualization appears in Settings and is disabled by default.
- Bag renders all ranks, supports live search, tier filter and sort, active A/B equipment rows, selected target slot and existing drag/tap to equip. Craft supports live search, tier, “only craftable” toggle, actual chance and ingredient/risk preview. Crafting RNG and item transactions unchanged.
- Restored Supabase verified-email signup via `/auth/v1/signup?redirect_to=<Cloudflare canonical>` and optional password recovery via `/auth/v1/recover`. To avoid unverified registration when Confirm Email is still OFF, the game first GETs public `/auth/v1/settings` and requires autoconfirm = false.
- Existing in-game password update and cloud revision-safe save remain unchanged. No database DDL, API secret keys or user-data writes from release engineering.

## Manual / unverified acceptance
- Supabase operator must set Authentication → Email → **Confirm Email = ON** and configure a validated custom SMTP sender to let real players confirm registration. Current Supabase connector does not allow changing those settings; no guarantee of actual delivery.
- Manual true-device Safari/HarmonyOS long play, sprite QA and 2-device cloud synchronization still required. Chromium simulated viewport is not a replacement for physical-device testing.
- Hitboxes are **elliptical approximations** aligned with creature body class, not pixel-perfect polygons. For combat reliability this avoids gaps and overhits while maintaining predictable 60Hz behavior.
- Old Netlify browser-local characters do not automatically migrate between origins; no forced redirects or reset performed.
