# Petal Realms V5.9.3 QA — crafting safeguards and collider broadphase

## Source and compatibility
- Base revision: V5.9.2 GitHub `main` `88b941ffab1c12457a2f80315aa274a8e34b8d10`.
- No changes to public Supabase table definitions, Auth user IDs, session keys, inventory rarity math, ten-strike limit, original crafting success probabilities, or Cloudflare hosting.
- Existing save format remains `version:5`. New optional field `protectedPetals` maps valid `petalType@rarity` keys to `true`. Loading older saves treats protection as empty; nonboolean, invalid or excessive keys are ignored.

## Mechanic
- A selected craft ingredient can be protected or unprotected from the touch-friendly crafting panel.
- Protection blocks the internal crafting function before drawing randomness or subtracting inventory, including one-off and 5-attempt batch actions. Both action buttons disable when the selected ingredient is protected.
- Bag and craft cards display protection status; available-to-craft filtering omits protected ingredients.
- Toggle writes the original Save/Outbox pathway and does not mutate material quantity.

## Collision
- Monster pair separation still scans all pairs, but uses a conservative squared-distance envelope `(a.r+b.r+2)^2` before `Math.hypot` / rotated ellipse support evaluations.
- This cannot exclude true collisions given `mobCollider` radii less than or equal to `mob.r`; original precise contact and displacement logic is otherwise retained.
- Per-mob player-contact radius computation now happens only when exact overlap is confirmed.
- The total traversal remains O(n²). The objective is to remove expensive trigonometry on physically distant mobs, not to make unmeasured framerate guarantees.

## Automated gates
- GitHub Actions static JS syntax, existing cloud save/auth/talent/tactical/Realtime/Cloudflare and V5.9/V5.9.1/V5.9.2 regressions.
- New `node tests/v593_protection_broadphase.cjs`: lock/unlock, no RNG/material consumption for protected items, unlocked crafting, optional-save validation, visual UI guard, randomized directional collision safety, and spaced-mob pruning.
- GitHub Playwright desktop/mobile browser inventory checks must remain green.

## Outstanding manual acceptance
- Native Safari/HarmonyOS long-play performance measurement, large mob stress test with profiler, real Supabase SMTP signup and cross-device cloud save regression are not certified by Node or mocked browser checks.
- This version does not implement server-authoritative multiplayer; experimental Realtime position rooms remain separate.

## Rollback
Revert the V5.9.3 merge on GitHub and verify Cloudflare production commit. New `protectedPetals` JSON remains harmless to older game versions but an older client cannot enforce crafting protection, so only use current V5.9.3 for locked inventory.
