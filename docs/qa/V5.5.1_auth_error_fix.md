# V5.5.1 authentication error UX

## Issue
When Supabase Auth returned `400 invalid_credentials`, the game showed the raw English message `Invalid login credentials`. This made it unclear whether the player should log in, register, recover a password, or use a legacy local account.

## Change
- Cloud Auth errors now retain the backend's stable `code` and HTTP status internally.
- Map common account errors to actionable Chinese guidance without exposing whether a particular email exists.
- Show default email-registration guidance next to login/register tabs.
- Keep password recovery and legacy local-account routes visible and unchanged.
- Never transmit passwords to GitHub/Netlify; no database schema, saved player JSON or RLS modifications.
