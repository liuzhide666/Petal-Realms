# Petal Realms V5.7 — QA Report (2026-10-17)

## Implementation
- **Monsters:** Six original special-AI archetypes: venom, predictive snipers, telegraphed chargers, summoners, nova, and temporary shields. Threat depends on biome level, elite status and rarity; high rarity gains bounded armor. All moves are session-local at fixed 60Hz.
- **Active abilities:** Z storm, V ten-projectile volley, F barrier, E heal, G overdrive; usable from desktop or touch, each on an independent cooldown. Q dash, attack/defend and A/B sets remain.
- **Set synergies:** assault, fortress, nature, artillery, scout; 2/4-piece thresholds. Switch between A/B to recompute perks.
- **World events:** weighted swarm, treasure rain, bloodmoon, healing wind, falling stars. Server-authoritative multiplayer randomization is not claimed.
- **Opt-in presence:** experimental room codes and cloud-user gating, plus Supabase WebSocket Presence/Broadcast; position/level only. No shared damage or loot; no private chat, trading, or server-side anti-cheat.

- No production Auth/SMTP test or cross-device save recovery test performed.
- Browser tests use Chromium with simulated/unprivileged local/guest sessions, not long-play native mobile.
- No Supabase database migration, server gameplay state, or secret keys were added.
- The game save payload is still `version:5`; all new combat/world states are ephemeral.
- New difficulty multipliers are original game balance inspired by genre patterns, not official florr.io numerical reproduction.
