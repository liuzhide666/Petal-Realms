# Petal Realms V5.4 · Regression Report

Date: 2026-10-17. Source baseline: V5.3 / `d5df0288537c2d6bb8e740624280b36811f2ec60`.

## Gameplay changes

1. **Seven-second elimination combo**. Each kill within the timer increments the combo. XP bonus rises 5 percentage points per additional kill, capped at +50%. Combo expires after seven simulated seconds, and resets on death/map transition. No new persisted fields.
2. **Guardian frenzy phase**. Guardian mobs below 35% HP gain +33% movement speed, +20% outgoing collision/projectile damage, and approximately 40% shorter ranged firing intervals; the guardian HUD displays live HP and frenzy status.
3. **Rare-loot radar**. Epic or higher ground loot is visible as colored pings on the minimap. Ultra or higher loot displays a pickup toast.
4. Existing ten-hit-per-60Hz-tick petal collision rule remains unchanged.
