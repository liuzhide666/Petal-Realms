# V5.19 candidate audit and verification

## Findings fixed

1. Fatal poison, meteor, body contact, nova and hostile-projectile paths continued the current update into healing, collection or retaliation. The tick now exits at the next fatal source boundary. HP remains zero while dead.
2. Death and respawn retained held keyboard/joystick references. Both now reset input; respawn also snaps the camera, refreshes HUD and restores canvas focus.
3. Blocked venom contacts applied poison during dash immunity or hit grace. Status attachment now requires accepted damage.
4. Friendly shots hit an enclosing circle outside the visible short torso axis. They now share the existing oriented torso predicate with melee.
5. A reward at level999 created an unsavable level1000. The runtime now respects the server level ceiling and loader XP ceiling.
6. Monster damage numbers included overkill; exchange numbers accumulated pre-armor damage. Numeric receipts and exchange feedback now use effective HP loss. Existing fang/chain bases remain explicit and unchanged.
7. Failed saves could schedule another flush from finally, including expired authentication; missing Retry-After produced NaN delays. Success scheduling and transient retry classification are now separate, with finite bounded delays and preserved outbox bytes.
8. Five encounter-layout assertions reproduced guardian/event/status/tool overlap. All five viewport fixtures now pass their separation checks.
9. Dropped petals used platform-dependent glyphs. All29 families now use the original shared outline renderer and respect reduced optional motion.

## Review scope and remaining work

The review covered fixed-step phase ordering, damage/status entry points, death/respawn, attack/defense input ownership, shared enemy collision geometry, projectile and reward progression, native account validation/CAS boundaries, flush/retry flow, shared loot rendering, and concurrent encounter HUD states. Prior crafting DP, item conservation, protected materials and presentation/RNG isolation remain in the regression set.

The official Florr guest page did not connect to a combat world. Its interface entry and floating background were visible. Official search describes enemies and rare-petal collection; community sources are not treated as numerical authority. Original art and independent rules remain the implementation basis.

Deferred: authoritative shared-world multiplayer and economy, complete ordered replay, pity, general elemental matrices, exhaustive physical-device QA and continuous swept projectile collision. A fixed-step torso test does not establish CCD. This audit is not a declaration that every future mechanism or possible game state is complete.
