## 2. 三条路线比较与选择

| 路线 | 玩家体验 | 系统设计 | 工程成本/风险 | 本轮选择 |
| --- | --- | --- | --- | --- |
| 主线保全，先改善反馈，再独立训练 | 不丢既有成长，可直接体验改善 | 把新挑战与旧经济隔开，能收集战斗数据 | 复用原模块，迁移少，可独立回滚 | 采用；执行者依据用户连续实施授权作出 |
| 另开独立赛季/存档 | 可以大改等级与奖励 | 规则更整齐，但两套经济并存 | 需要独立保存、账号入口、运营和内容维护 | 需要大规模重新平衡时再评估 |
| 直接重做当前主线 | 新老玩家立刻面对新曲线 | 旧库存价值和概率分析可能失效 | 必须有映射、补偿、双版本读写和回退方案 | 当前不采用 |

## 3. 已落地的相互关联改动

1. **存档恢复**：版本冲突自动展开比较，准确解释原因；显示双方等级、击败数、库存与版本。核对期间变化要重新选择；备份先行，读取失败恢复旧待同步入口，不覆盖新记录。版本号/等级/总片数不能代替装备价值判断。
2. **合成体验与守恒**：单次/批量共用一次接受路径，结算后先尝试持久化，再演出。五瓣汇聚、成功出现、失败散落、混合批次及减少动画；可跳过。实际消耗/产物/剩余材料可读，不能重播发奖。目标库存满时扣料前拒绝，概率分布也吸收于剩余空位。
3. **技能视觉**：风暴固定范围余波、齐射实际方向弹体、治疗叶片与有效恢复、持续屏障与超载计时。原有伤害/冷却系数保留；满血治疗不浪费冷却。最多12个短时技能标记，低画质减少装饰而保留有效状态。
4. **战术训练**：暂停菜单进入；复制双构筑，暂停主线，独立地图与随机域，退出恢复主线世界/RNG。不提供经验、掉落和永久奖励。可调敌方等级/品质，三波、180秒上限、至少1.5秒预警、上限24实体。
5. **四面楚歌**：分工使用已有牵制、冲锋和远程行为；每波轮换突破方向，必须完成路线和清敌两项。无障碍训练场，初始通道检查包含最大泥土体型；移动敌人仍能争夺通道。
6. **背水一战**：35%生命开始，三波共享3次成功主动技能使用；被动治疗仍有效，形成构筑与时机选择。没有“残血自动多倍伤害”和主线残血刷奖励。
7. **数值观察**：训练记录封顶有效伤害、实际承伤、主动恢复和战斗阶段时间。输出效率包含走位/装填停机；不能以此评选所有场景的最优构筑。

统一视觉继续使用草木绿、奶油文字、金色决策提示、不同品质边框与原有生物描边。危险信息优先于装饰；失败不以强闪光惩罚玩家。触屏控制、焦点、滚动与短横屏采用现有布局并回归。音效未在本轮加入；新音频需处理用户激活、静音、并发限幅、后台恢复与来源许可。

## 4. 成长、数值与经济的实际审计

六类天赋各5级，共30点；每两级获得1点，61级后基础天赋已无新增消费项。槽位在1/5/12/20/30级达到6/7/8/9/10。等级仍可到999。这是源码推导，不是玩家留存统计。

当前升级经验为35+floor(18L+0.9L²)。不凭“后期升级慢”的直觉全局减半：先测风险、有效击杀时间、每分钟实际获取与阶段目标。普通/精英/守卫的建议TTK靶区仍属于待实验目标，不作为已达标数字。

固定独立成功概率、失败消耗均匀1—4且持续补足材料时，首次成功平均同级材料消耗为5+2.5(1-p)/p。Ultra→Super为252.5，Super→Unique为5，Unique→Eternal为1002.5。此跳变是现行原创规则，不能冒充florr官方规律。有限库存、批量五次、产物空位与递归成本是不同问题。

源码绑定分析工具执行25,056个单次命中条件组合、原生刷怪分支与八种减伤组合，并对九级合成各做30,000个独立种子样本。矩阵考虑29类花瓣、品质、耐久、天赋、套装、超载、护甲和暴击；它不是有走位/目标切换的完整DPS仿真。训练中的实际统计补足接触/停机信息，两者不能混用。

后续应先选代表性流派固定种子录像/输入，再做数值模型与反例测试。候选：高爆发低耐久、持续治疗防御、远程弹射控制、移动拾取探索。检查不同品质/体型/护甲/敌群、治疗溢出、有限护甲层、冷却空窗、被动堆叠与无限控制。没有实测支持前不宣称不存在支配流派。

## 5. 后续完整系统设计与优先级

| 优先级/状态 | 系统 | 下一项有用改动 | 验收/依赖 |
| --- | --- | --- | --- |
| P0 已实现，候选验证 | 存档、合成、终止状态 | 本轮恢复与守恒保护 | 当前原生API、异步代际变化、快速输入、动画取消、退出/刷新检查 |
| P1 已实现，候选验证 | 动画、HUD、技能 | 本轮独立效果与实际计时 | 五视口、中文字体、低画质、减少动画、RNG不变、真实计时 |
| P1 已实现，训练版 | 挑战/复盘 | 两模式、记录、原世界恢复 | 路线+清敌/资源预算、胜利/死亡/超时/取消、无奖励泄漏 |
| P1 需要持续试玩 | 首领与AI | 预警→行动→恢复，近战压迫/远程封路/可打断支援；避免同时无解攻击 | 列出每招反制窗口；帧率变化不改判定；角色组合挑战优于纯加血 |
| P2 仅设计 | 后61专精 | 少量互斥技能变体，改变走位、节奏或装备协作；可退点试配 | 点数合法性、旧存档映射、服务端校验、原工作台评分边界 |
| P2 仅设计 | 装备生态 | 明确爆发/持续/控制/防守/探索价值，展示副作用及同槽前后差异 | 持有数量守恒、替换满仓拒绝、双构筑回退、真实使用率数据 |
| P2 需要经济模型 | 合成/强化/回收 | 在配方、定向获取、有限保底中选择一条有成本的路线 | 保底状态会破坏独立试次；必须更新分析、存档、迁移与补偿规则 |
| P2 仅设计 | 探索/地图 | 每区特色危险与资源路线、稀有遭遇、隐藏目标和可选精英词缀 | 路线可达、出生安全、风险与奖励、任务不制造重复劳动 |
| P2 仅设计 | 教学/失败反馈 | 逐步说明攻击外扩、守势修复、技能时机、死因和可检验建议 | 可跳过；不伪造最优建议；新增读屏文字不遮挡操作 |
| P2 已有诊断，未达真机验收 | 性能/架构 | 保留警戒/判定，按实测热点裁剪装饰、复用绘制资源和减少重绘 | 分开量逻辑、提交绘制和像素读回；参考硬件P50/P95/P99；真机热/电量另测 |
| P3 依赖服务器权威 | 奖励挑战/合作防守 | 运行ID、验证完成条件、幂等账本、归属、断线恢复 | 当前客户端进度不能支持可信交易/排行榜/共享奖励；位置房间不等于多人战斗 |

内容扩展备选包括精英狩猎、Boss Rush、限时突破、环境灾变、花瓣限制和合作防守。每项必须先有独立的进入/胜负条件、可反制机制、目标、奖励/滥用分析与测试；没有这些不以改怪量/血量计为新模式。

## 6. 推进与回退

顺序调整依据：先消除用户已遇到的存档阻断及物品损失风险；再增加结果可读的动画；用无奖励训练验证挑战和统计，再决定经济/后期成长迁移。不会因为“全面升级”而同时更换框架、数据库、全部成长曲线。

每个候选通过本机单元/API、完整浏览器回归、Worker构建、独立审查后才评估合并。保留基线提交与独立提交；代码回退不等于数据库回退。本轮不要求数据库迁移，也不操作生产账号。正式发布必须另有当前授权和当前CI/部署检查。

外部来源、版本冲突及未取得内容见[研究记录](../research/2026-10-24-reference-ledger.md)；实际行为合同见[S4](../standard/V5.20_BLOOM_TACTICS.md)。具体通过数量与剩余缺口以本分支最新QA为准。
